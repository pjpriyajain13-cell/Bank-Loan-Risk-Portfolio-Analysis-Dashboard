# Bank Loan Analysis

## 📌 Project Overview

This project analyzes bank loan data to understand loan performance, borrower characteristics, credit risk, interest rates, and repayment patterns.

The analysis was performed using **Power BI** to create an interactive dashboard for financial and risk analysis.

## 🎯 Business Objectives

The main objectives of this project are to:

* Analyze overall loan portfolio performance
* Understand loan distribution by borrower characteristics
* Analyze loan status and default behavior
* Identify different risk categories
* Analyze interest rate patterns
* Evaluate borrower income and EMI burden
* Analyze debt-to-income ratio
* Compare loan performance across different segments
* Provide data-driven insights for lending and risk management

## 📊 Dataset

The dataset contains:

* **1,552 loan records**
* **51 fields**

### Key Variables

| Category         | Variables                                            |
| ---------------- | ---------------------------------------------------- |
| Loan Information | Loan Amount, Funded Amount, Loan Term                |
| Interest         | Interest Rate, Interest Received                     |
| Borrower Profile | Annual Income, Employment Length, Home Ownership     |
| Credit Risk      | Credit Inquiries, Delinquencies, Public Records      |
| Debt             | Debt-to-Income Ratio, EMI Burden                     |
| Loan Performance | Loan Status, Default Flag                            |
| Risk             | Risk Category, Interest Category                     |
| Payments         | Total Payment, Principal Received, Interest Received |
| Geography        | State, ZIP Code                                      |

## 💡 Key Business Questions

The dashboard helps answer questions such as:

1. How large is the overall loan portfolio?
2. What proportion of loans are fully paid, current, or charged off?
3. Which borrower segments have higher default rates?
4. How does risk category vary across borrowers?
5. How does interest rate vary across loan segments?
6. What is the relationship between income and loan amount?
7. How does debt-to-income ratio affect borrower risk?
8. Which states have higher loan activity?
9. How does EMI burden vary across borrowers?
10. How much interest has been received from the loan portfolio?
